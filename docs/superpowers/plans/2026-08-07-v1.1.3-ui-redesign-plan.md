# Prodash v1.1.3 UI 升级实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Prodash 建立一套深色主题设计系统，解决信息过载、导航混淆、原生控件未样式化等问题，完成 UI 全面优化并升级到 v1.1.3。

**Architecture:** 引入 Radix headless primitives 处理交互无障碍，使用 Lucide 统一图标，将全局 CSS 拆分为 tokens/base/primitives/components 四层，分阶段迁移业务组件并保留旧样式作为 fallback，最终清理旧 CSS。

**Tech Stack:** React 18 + Vite 8 + 原生 CSS + Radix UI primitives + classnames + lucide-react

## Global Constraints

- 版本目标：`v1.1.3`（对外 API/数据模型/页面路由不变，仅 UI 与样式架构升级）。
- 不引入 Tailwind CSS、shadcn/ui、图表库。
- 保留旧 `theme.css` 和 `components.css` 作为 fallback，直到新样式验证完成。
- 所有交互元素必须有可见焦点环（`--focus-ring`）。
- 支持 `prefers-reduced-motion`。
- 组件使用 BEM-like 命名：`component`、`component__element`、`component--modifier`。
- 状态类前缀：`is-` / `has-`。

- [ ] **Step 3: 实现 Button 组件**

Create `src/components/primitives/Button.jsx`:
```jsx
import cn from 'classnames';

export default function Button({
  children,
  variant = 'default',
  size = 'md',
  isLoading = false,
  disabled = false,
  className,
  ...props
}) {
  return (
    <button
      className={cn(
        'btn',
        `btn--${variant}`,
        `btn--${size}`,
        { 'is-loading': isLoading },
        className
      )}
      disabled={disabled || isLoading}
      {...props}
    >
      {isLoading && <span className="btn__spinner" aria-hidden="true" />}
      {children}
    </button>
  );
}
```

import * as RadixTooltip from '@radix-ui/react-tooltip';

export default function Tooltip({ children, content }) {
  if (!content) return children;
  return (
    <RadixTooltip.Provider delayDuration={200}>
      <RadixTooltip.Root>
        <RadixTooltip.Trigger asChild>{children}</RadixTooltip.Trigger>
        <RadixTooltip.Portal>
          <RadixTooltip.Content className="tooltip-content" sideOffset={4}>
            {content}
            <RadixTooltip.Arrow className="tooltip-arrow" />
          </RadixTooltip.Content>
        </RadixTooltip.Portal>
      </RadixTooltip.Root>
    </RadixTooltip.Provider>
  );
}
