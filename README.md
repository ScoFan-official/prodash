# 个人效率工作台（Prodash）

深色主题的个人效率网页，将待办、时间管理、笔记、记账集中在一个工作台里。当前版本实现「待办清单」（列表 + 艾森豪威尔四象限双视图）与「双轨任务计时」（人工工时 / Agent 运行时长，含统计与日报导出预留接口）。

- 在线地址：https://scofan-official.github.io/prodash/
- 当前版本：v0.2.1

## 功能特性

- **工作台外壳**：标题栏 + 顶部 Tab（待办 / 笔记 / 记账）
- **四象限待办**：添加任务时用「重要？」「紧急？」两个开关，自动归入四个象限
  - 重要·紧急 → 立即做
  - 重要·不紧急 → 计划做
  - 不重要·紧急 → 快速处理
  - 不重要·不紧急 → 尽量少做
- **三视图切换**：列表 / 四象限 / 统计三种查看方式，切换不丢数据
- **双轨任务计时**：每个待办拥有「人工工时」与「Agent 运行时长」两条独立轨道，可同时运行、无全局上限
  - 每条轨道支持开始 / 暂停 / 继续 / 停止，显示精度为分钟级，实际存储毫秒时间戳
  - 计时中删除待办被阻止；勾选完成时自动停止该待办的全部计时，历史记录保留
- **计时恢复**：基于绝对时间戳持久化运行状态，刷新页面、关闭浏览器后重新打开可恢复；回到前台时自动校正时长
- **顶部状态条**：待办页顶部显示正在计时的任务，点击可展开查看全部轨道与时长详情
- **统计视图**：今日工时汇总、人工 / Agent 时长与占比、按任务排行、按任务分类占比（使用现有 CSS/SVG，无新增图表依赖）
- **日报导出预留接口**：提供纯函数日报契约 `getReportData(state, todos, date)`（`state` 为 timeStore 计时状态对象，即 `{ active, records }`；返回含日期、双轨总时长、记录明细）与停止事件订阅点 `subscribe(listener)`，供后续 Dify 对接复用，不依赖 React
- **数据持久化**：待办与计时数据存浏览器 localStorage（待办 `prodash.todos.v1`、计时 `prodash.time-tracking.v1`），刷新不丢失；计时仅在开始/暂停/继续/停止及页面隐藏时写入，不在每次刷新时写盘
- **错误兜底**：读写失败不崩溃，页面给出友好提示
- **响应式**：深色主题，手机窄屏自动适配

> **0.2.0 范围说明**：本版本**不包含** Dify 对接、跨日切分和周/月趋势。日报仅提供客户端结构化数据契约与停止事件接口；跨日切分、周/月趋势等统计扩展与 Dify 适配留待后续版本。

## 技术栈

- React 18 + Vite 8（JavaScript）
- Vitest 4 + React Testing Library（测试）
- 纯前端单页应用，无后端
- 部署：GitHub Pages + GitHub Actions

## 本地开发

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器（默认 http://localhost:5173/）
npm test           # 运行全部测试
npm run build      # 生产构建（输出到 dist/）
npm run preview    # 本地预览构建产物
```

## 部署

推送到 GitHub 的 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。部署前需在仓库 `Settings → Pages → Source` 选择 **GitHub Actions**。

## 版本管理

项目使用 **SemVer（语义化版本）**，格式为 `主版本.次版本.修订号`：

| 更新类型 | 场景 | 版本号变化 | 命令 |
|---------|------|-----------|------|
| 主版本（MAJOR） | 破坏性变更，不兼容旧版 | 1.x.x → 2.0.0 | `npm version major` |
| 次版本（MINOR） | 新增功能，向后兼容 | 1.0.x → 1.1.0 | `npm version minor` |
| 修订号（PATCH） | Bug 修复，向后兼容 | 1.0.0 → 1.0.1 | `npm version patch` |

发版流程：

```bash
npm version minor        # 升级版本号（自动更新 package.json 并打 v1.1.0 标签）
git push origin main --tags   # 推送代码与版本标签
```

每个版本同时做两件事：**更新 `package.json` 的 `version` 字段**，并**打一个 `vX.Y.Z` 的 git 标签**，方便回溯任意一次更新。每次发版记得在本 README 的「版本历史」中追加一条记录。
